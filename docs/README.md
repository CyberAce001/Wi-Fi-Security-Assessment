# Docs

Supporting documentation behind the formal report.

- **`wifi_security_assessment_guide.md`** — Step-by-step methodology guide: lab setup, reconnaissance, Nmap scanning, OWASP ZAP testing, Wireshark traffic analysis, device-manager review, and findings consolidation, plus notes on limitations worth knowing before repeating this test.
- **`findings_log.md`** — Working findings/observations log kept during testing, including items that were investigated and ruled out (false positives), with the reasoning behind each call.
